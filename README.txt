NOMAD TRAVEL — туристический сайт для лабораторной
==================================================

Внутри папки проекта находятся отдельные файлы:
- index.html — HTML-каркас сайта;
- style.css — дизайн, сетки, адаптивная версия для телефона;
- script.js — страны, города, достопримечательности, маршруты, гиды, видео-ссылки и интерактивность;
- images/ — три локальные SVG-иллюстрации, подключённые относительными путями;
- report.txt — заготовка отчёта по лабораторной работе.

КАК ОТКРЫТЬ
1. Распакуй архив.
2. В VS Code выбери File → Open Folder и открой папку NomadTravel.
3. Открой index.html через браузер или запусти Live Server.
4. Для фотографий, шрифтов и видеоматериалов требуется подключение к Интернету. Три SVG-иллюстрации в images/ хранятся локально и работают без Интернета.

КАК УСТРОЕН САЙТ
Главная → Азия/Европа → регион → страна → достопримечательность → видео и история → тур и цена.
Добавлены направления Кыргызстан, Казахстан, Узбекистан, Таджикистан, Туркменистан, Грузия, Япония, Таиланд, Франция, Италия, Швейцария, Испания, Германия и Греция. Для каждой страны предусмотрены несколько мест и базовые маршруты.

ПУБЛИКАЦИЯ НА GITHUB PAGES
1. Создай репозиторий GitHub.
2. Загрузи index.html, style.css, script.js, README.txt и report.txt в корень репозитория.
3. Открой Settings → Pages.
4. Выбери Deploy from a branch, ветку main и папку /(root), затем нажми Save.
5. Дождись появления URL в Settings → Pages и открой опубликованный сайт.

ВАЖНО ДЛЯ ЗАЩИТЫ
- Цены демонстрационные, это не реальные коммерческие предложения.
- Номер телефона и email демонстрационные.
- Формы проверяют заполнение полей и показывают сообщение в браузере, но не отправляют данные на сервер и не создают реальную бронь.
- Карточки гидов, оценки и биографии созданы для учебного макета; портреты — внешние фото, они не подтверждают личность или квалификацию реальных гидов.
- Фотографии загружаются с внешних сайтов. Если источник изменится, откроется резервное изображение. Для коммерческого сайта нужно получить права/согласие на медиа и указать лицензии.
- Где доступно, кнопка видео открывает официальный туристический ресурс или ролик; в остальных местах она открывает поиск YouTube по названию достопримечательности.
